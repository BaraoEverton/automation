# 📦 Inventory control via WhatsApp

**Status:** 🟠 In development

Reuses the conversational architecture of [Vita](https://github.com/BaraoEverton/ai-conversational-systems/tree/main/vita-ai-receptionist) (event filter, message buffer, multimodal intake, interpreter with structured output, Postgres state) to let a small food business register stock entries and exits by WhatsApp text, audio or photo.

Next steps: inventory schema, stock-specific interpreter and confirmation messages.
